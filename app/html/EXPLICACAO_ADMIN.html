👨‍💼 Como o Sistema de ADMIN Funciona

1️⃣ IDENTIFICAÇÃO DO ADMIN

Quando você loga com:
Email: admin@inventario.com
Senha: 123456

O sistema sabe que é ADMIN porque:
No arquivo auth-system.js, existe uma verificação:
if (email === 'admin@inventario.com' && password === '123456') {
    // RECONHECE COMO ADMIN
    user.role = 'admin' ← Aqui define o ROLE
}

2️⃣ ARMAZENAMENTO DO ROLE

Após validar, o sistema salva no localStorage:
localStorage.setItem('clicktime_user', {
    email: "admin@inventario.com",
    role: "admin", ← ⭐ INFORMAÇÃO IMPORTANTE
    displayName: "admin",
    isGuest: false
})

3️⃣ APLICAÇÃO DA CLASSE CSS

Na página sistema.html, o código verifica:
if (user.role === 'admin') {
    // Adiciona classe no <body>
    document.body.classList.add('is-admin') ← Ativa CSS
}

4️⃣ ATIVAÇÃO DO PAINEL ADMIN

No CSS (theme-advanced.css), há regra:
body.is-admin .admin-panel {
    display: block !important; ← Mostra painel
}

body.is-admin [data-admin-only] {
    display: block !important; ← Mostra elementos admin
}

5️⃣ RESULTADO FINAL

✅ O que você vê como ADMIN:
• Painel lateral direito com customizações
• Botões de tema (Professional, Energia, Relax)
• Seletor de cores personalizado
• Botão de logout
• Cor de fundo diferente na página
• Badge "👑 ADMINISTRADOR" no login

🎛️ Funções de Admin Explicadas

1. CUSTOMIZAR CORES

O que faz: Permite escolher qualquer cor para o sistema
// Admin clica em um preset ou color picker
applyPreset('energy') // Ou
themeManager.setTheme('#ff5733')

// Sistema aplica a cor em:
- Botões (gradient)
- Borders (inputs)
- Shadows (efeitos)
- Destaques gerais

2. LOGOUT

O que faz: Deconecta o admin e volta para o login
function logout() {
    // 1. Mostra alerta
    Swal.fire({ title: 'Desconectado!' })

    // 2. Limpa dados
    authManager.logout()

    // 3. Remove classes CSS
    document.body.classList.remove('is-admin')

    // 4. Redireciona após 500ms
    window.location.href = './login.html'
}
